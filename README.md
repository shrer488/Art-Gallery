# Ink & Water

A walkable 3D virtual exhibition of artworks by Riya.

## 👉 [Walk the gallery](https://claude.ai/artifact/4zru1yBVBXuHgjKrhUH1kV)

https://claude.ai/artifact/4zru1yBVBXuHgjKrhUH1kV

Walk with WASD or the arrow keys (tap to walk on a phone), click a painting to see it up close, and press E near a bench to sit.

## Files

- `index.html` – the whole gallery (Three.js)
- `art/` – the artworks
- `favicon.svg` – the lantern icon
